# Marquee — Desktop App

Marquee is a personal tracker for critiques of movies, shows and games, with a cinematic theme picker and a local music library.

This repo hosts the downloadable desktop installers. Grab the right one for your computer from the **[Releases](../../releases/latest)** page:

| Platform | File |
|---|---|
| Windows (installer) | `Marquee-Setup-Windows.exe` |
| Windows (portable, no install) | `Marquee-Portable-Windows.exe` |
| Mac — Intel | `Marquee-Mac-Intel.zip` |
| Mac — Apple Silicon (M1/M2/M3/M4) | `Marquee-Mac-AppleSilicon.zip` |

## First-run note

These builds aren't code-signed, so your OS will flag them as unrecognized the first time:

- **Windows:** SmartScreen will show "Windows protected your PC." Click **More info**, then **Run anyway**.
- **Mac:** Gatekeeper will say the app "cannot be opened." Right-click (or Control-click) the app and choose **Open**, then confirm in the dialog that appears. You only need to do this once.
